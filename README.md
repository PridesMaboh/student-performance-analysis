Student Performance Analysis — Business Intelligence Program

Overview
This project analyses performance data from 79 students enrolled in a Business Intelligence program. The goal is to identify the factors that influence academic success, understand study behaviour, and provide actionable recommendations for program improvement.

Tools Used
Excel
Python
SQL (PostgreSQL)
R
Power BI
Tableau

Key Features
Full multi‑tool data cleaning pipeline
Exploratory Data Analysis (Python, Power BI, Tableau)
Insights on study behaviour, education background, residence type
Regression model with dummy encoding (R² = 0.71)
Actionable recommendations for program improvement
Complete project documentation included
